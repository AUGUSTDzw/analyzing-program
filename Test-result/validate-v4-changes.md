# 两项未验证改动的验证结果

两项改动都在 `b703918` 提交，都只有设计理由没有实测。本文档给出在**不依赖新生成**的条件下
能得到的全部证据。

---

## 改动一：A8 模板（示例改为「一步两块，每块各自三层」）

### 已验证：机制成立，且可重复

v3 的证据是**模型照抄示例而不是遵守规则** —— 加了禁令没效果，因为示例从未演示过被禁的形状。
既然示例是承重件，示例本身就可测。

新增 `check_skill_selfconsistent.py`：用闸门自己的 A8 逻辑检查 skill 里的教学示例。

```
three-layer section: 2199 chars, 2 source block(s)
  ok    every block in the example carries all three layers
  ok    a step in the example holds two code blocks (2 in step 2)
```

**负向对照**：把步骤②第一块的三层标签删掉（v3 失效的那个形状）→ `exit=1`，
由「一步两块」这条断言捕获。测试不是空转的。

手工核对确认示例是真的「一步两块、每块各自三层」，不是碰巧过闸门：

```
#### ② 声明与取描述（两步代码，块级三层）
```abap   ← 声明
**做什么** … **为什么** … **风险与改进** …      三层齐
```abap   ← FOR ALL ENTRIES 查询
**做什么** … **为什么** … **风险与改进** …      三层齐
```

反模式第 2 条正面点名「把一个声明段切成两块」。

### 仍未验证：模型行为是否改变

自检证明的是**示例自洽**，不是**模型会照做**。后者仍需生成，而 FI toolkit 子代理已连续 5 次
不可靠、AVE 29.5k 行同样截断。所以这一项的准确标签是：

> **机制已验证，效果未测量。** 且现在有了一条常驻回归检查，以后每次改 skill 都会自动验。

## 改动二：4 个激活问句

### 回溯测试：在 v1 漏掉的缺陷上逐条试

用冻结的 20 条缺陷清单，取 v1 判分里漏掉的 6 条（4 partial + 2 no），
按问句**字面**（不是善意转述）判定能否命中：

| 缺陷 | 判定 | 命中 | 原因 |
|---|---|---|---|
| D16 | **是** | Q3 | `INSERT ... ASSIGNING` 撞 UNIQUE 键，重复键返回码未处理 → 字段符号未赋值即解引用 |
| D3 | 邻近 | Q2 | `WITH TABLE KEY` 用于 NON-UNIQUE 键。需要把 Q2 读成「这个键类型对该语句合法吗」 |
| D5 | 邻近 | Q3 | `sy-subrc` **检查了**，问题是检查的是循环体残留值。问「是否检查」不问「是否检查对了」 |
| D18 | 邻近 | Q2 | 明表赋给 UNIQUE 键 HASHED 表会抛 `CX_SY_DUPLICATE_KEY`，但行类型兼容，没有「不合法」可言 |
| D2 | 够不着 | – | 需知道 `##WARN_OK` 抑制了多行 finding；`SELECT SINGLE` 检查了返回码却仍取任意行 |
| D12 | 够不着 | – | 需知道域值 `ALLGAZMD-E` 是「演练运行」的业务含义 |

**6 条漏检：1 条干净命中，3 条邻近，2 条够不着。**
**6 条错误论断：1 条邻近，5 条够不着**（只有「`lv_fname(5)` 长度算错」沾 Q4，其余是域值语义、
LUWI 嵌套、方法计数、代码自相矛盾、数据流误判）。

按此样本，**最好情况是召回 0.700 → 0.750（+5pp）**，远低于 30pp 门槛。

### 但这个空白是真实存在的

v1 基线（`2cced57`）里：

| 关键词 | 出现次数 |
|---|---|
| `sy-subrc` | **0** |
| 返回码 | **0** |
| 掩码 | **0** |

所以 Q3/Q4 不是把已有内容换个说法，而是**填一个 v1 完全空着的类**。
而且这个类是否有价值，不该由这 20 条样本决定 —— iteration-8 的逐缺陷数据独立显示
skill 在这一类上净负（约 7/9 条净负缺陷属于可机械检查类，合计约 −300pp）。

### 判定

> **保留，标注为「未测量」。** 空白可证明地在 v1 里是开的；回溯测试没给出支持，
> 但也只否定了这个 20 条样本，且否定的 5 条恰好都是「需要业务/域值语义」那一类 ——
> 那本来就不是四个是非问句该负责的。

## 与本项目既有标准的一致性

本项目此前有两次「加了但没帮助」被回滚（深度分档规则、具体错误反例表）。
两项改动都没有支持性证据，差别在于：

- A8 模板：把一条**已测出无效**的禁令换成示例演示，而示例现在**可自动验证**。
- 4 问句：填一个**可证明为空**的类，方向由 iteration-8 独立支持，但效果未知。

两者都不满足「>30pp 才接受」的门槛。**所以它们的标签都是未测量，
不是「已验证有效」。** 差别只在于一个有常驻回归检查保底。
