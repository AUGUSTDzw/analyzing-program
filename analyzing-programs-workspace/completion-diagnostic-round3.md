## 2. 本轮设计

| 项 | 取值 |
|---|---|
| skill 版本 | 1.0.3 = `fac4d5a3`，安装位 `C:\Users\DzwU\.agents\skills\analyzing-programs\SKILL.md` |
| 源码 | `zcl_abapgit_objects_program`（1597 行，sha `bf5661698e3d`）——两轮符合性探针里**两次都静默**的那个文件 |
| C1 | 3 次单次写，prompt 与第一轮标准版逐字相同 |
| C3 | 3 次增量追加写，prompt = C1 的 prompt + 增量追加写的要求 |
| 派发 | 6 次**同时**发出 |
| 记录 | 每次派发：尝试号、是否产出、字节数、是否静默、是否工具级中断 |

**关于"同时发出"**：两臂各 3 次、同批发出，负载对两臂对称，所以 C1 与 C3 的**对比**
不受并发影响。但**绝对完成率与前两轮不可比**（前两轮是每次 2 个并发）。
若两臂同时塌到接近 0，先怀疑并发资源，而不是先下机制结论——这条写在这里，
是为了在结果难看时约束解释。
