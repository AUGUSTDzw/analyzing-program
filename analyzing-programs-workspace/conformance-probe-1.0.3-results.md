## 4. 一项必须标注为不可判定

`objects_program` 的 run-log **只逐字抄了命令**（含 `"EXITCODE=$LASTEXITCODE"` 这个表达式），
**没有把退出码数值单独抄下来**。所以第 3 项在该格无法从日志判定。
能确认的只有两件事：agent 自报两道闸门最终都是 0，以及我自己独立跑闸门得到 `PASS` / 退出 0。

按预注册规则，未达成不等于不可判定——这一项记**不可判定**，不记达成也不记失败。
这是 run-log 格式的差别，不是 skill 的差别：第一轮两个 agent 都抄了数值，
这一轮只有一个抄了。

## 6. 这批数据不能回答什么

与预注册 §5 一致：只判**可执行性**。不判质量、单臂无对照，
**不得书写任何准确率、召回、版本优劣的断言**。

与第一轮同源的污染仍在：要求写 run-log 让"日志里有退出码"变得平凡；
有判别力的仍然是**拿非零退出码之后做了什么**。
